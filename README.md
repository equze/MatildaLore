# Matilda Lore — прототип 4.0

Matilda Lore — сайт-каталог лора Матильды. Главный заголовок сайта — «Лор Матильды». Каталог строится из разделов; первый раздел — «Истории», внутри него размещаются отдельные истории и переписки. Он может содержать истории, переписки, хронологии, персонажей, места, отношения, документы, воспоминания и другие части лора.

## Структура проекта

- `index.html` — единственный HTML-файл: главная страница, каталог, меню, окно пароля и просмотр материала.
- `style.css` — оформление сайта, карточек, чата и блоков разметки.
- `script.js` — меню, сортировка, загрузка материалов и проверка пароля.
- `story-format.js` — преобразование TXT-разметки в элементы сайта.
- `stories/` — TXT-материалы и папки с медиафайлами.
- `passwords.txt` — демонстрационные пароли по идентификаторам материалов.
- `HISTORY_FORMAT.txt` — полная инструкция для нейросети по созданию материалов Matilda Lore.

Отдельная страница чтения не используется. Материал показывается внутри `index.html`.

## Запуск

Открой папку проекта в VS Code и запусти Live Server. Либо выполни из папки проекта:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

Не открывай `index.html` двойным кликом: браузер может блокировать загрузку TXT-файлов через `fetch`.

## Разделы сайта

Главная структура каталога рассчитана на несколько независимых разделов. Сейчас создан первый раздел — «Истории». Каждая карточка внутри него является отдельным подразделом и открывает самостоятельный TXT-материал. При добавлении будущих разделов их следует выводить на том же уровне, что и «Истории», а не помещать в список историй.

## Сортировка

В каталоге доступны четыре режима:

- Дата события или переписки: сначала новые.
- Дата события или переписки: сначала старые.
- Номер: сначала первые добавленные на сайт.
- Номер: сначала последние добавленные на сайт.

Для каждой карточки в `index.html` указываются:

- `data-date="2026-11-08"` — дата переписки или события в формате `ГГГГ-ММ-ДД`.
- `data-order="1"` — порядковый номер добавления материала на сайт. Он не зависит от даты переписки.

При добавлении нового материала дата `data-date` должна соответствовать содержанию, а `data-order` — времени добавления на сайт.

## Добавление нового материала

1. Создай TXT-файл в папке `stories/` согласно `HISTORY_FORMAT.txt`.
2. В начале TXT-файла укажи `# Название материала`, а следующей строкой `!date: ДАТА`.
3. В `index.html` скопируй карточку и укажи уникальные `data-story`, `data-title`, `data-date` и `data-order`.
4. В `script.js` добавь путь к TXT-файлу в объект `storyFiles`, используя тот же идентификатор.
5. В `passwords.txt` добавь строку `идентификатор=пароль`.
6. Убедись, что номер добавления уникален.

Разметка поддерживает диалоги, стили сообщений, главы, временную шкалу, досье персонажей, локации, отношения, сцены, заметки Матильды, документы, цитаты, списки, таблицы, скрытые фрагменты, изображения, аудио, видео и вложения. Полный список находится в `HISTORY_FORMAT.txt`.

## Тестовый доступ

Идентификатор: `exchange-info-08-11-2026`.
Пароль: смотри `passwords.txt`.

## Безопасность

Текущая версия — статический прототип. Проверка пароля выполняется в браузере, а TXT-файлы и `passwords.txt` остаются публичными статическими файлами. Это не настоящая защита приватности. Для реальной защиты потребуется серверная авторизация, который будет отдавать текст только после проверки пароля.
